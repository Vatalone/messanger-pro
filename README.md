Messenger Application
A full-featured real-time messenger application with media sharing and profile management capabilities.

✨ Features
User Authentication & Registration - Secure sign-up and login system
Real-time Chat - Instant messaging with WebSocket connection
Media Sharing - Send images, videos, and files in conversations
Online Status - Real-time user presence indicators
Read Receipts - Message read confirmation system
Profile Management - Edit profile information and upload avatar images
Typing Indicators - See when someone is typing a message

🛠 Technology Stack
Frontend
React 19 - UI library
React Router DOM 7 - Navigation and routing
React Hook Form - Form handling and validation
Axios - HTTP client for API requests
Socket.IO Client - Real-time WebSocket communication
Tailwind CSS - Utility-first CSS framework
React Hot Toast - Toast notifications

Backend
Node.js + Express 5 - Server framework
Socket.IO - WebSocket server for real-time features
MySQL + Sequelize ORM - Database and object-relational mapping
JSON Web Tokens (JWT) - Authentication
Bcryptjs - Password hashing


📱 Core Functionality
Real-time Communication
Instant message delivery using WebSockets
Live online/offline status updates
Typing indicators during conversations
Read receipts with timestamps

Media Management
Upload and share images directly in chat
Support for various file formats
Cloud-based media storage via Cloudinary
Automatic image optimization

User Experience
Responsive design for all devices
Real-time notifications for new messages
Smooth transitions and loading states
Form validation with immediate feedback

Security
JWT-based authentication
Secure password storage with bcrypt
Protected API endpoints
Input validation and sanitization
Cloudinary - Cloud media storage and management

Multer - File upload handling
